# IRR Guard MCP v0.1.0

First public research/demo release.

## Included
- IRR core with proportional traceability levels.
- Material-incidence assessment.
- Layered legal-source verification.
- Objective alert/incidence register and resolution flow.
- Human ratification gate and deliberative pause.
- SHA-256 event-chain integrity and final report hash.
- MCP-style HTTP endpoint plus stdio adapter.
- Web wizard for live talks/demos.
- Smoke test, Dockerfile, academic citation metadata and open-source license.

## Important
This is not connected to KENDOJ, Delfos, CENDOJ or any official judicial system. Do not process real case files or personal data with this release.
